# Defect case studies

This directory will preserve a small number of meaningful defects from discovery through regression protection.

Each case study should contain:

- User-visible symptom and impact
- Minimal reproduction
- Logs, screenshots, test output, or traces
- Root-cause analysis
- The code change
- The regression test and its chosen layer
- Remaining limitations

Do not manufacture defects after the implementation is complete. Capture authentic failures encountered during development or deliberately test a documented risk before implementing its protection.
